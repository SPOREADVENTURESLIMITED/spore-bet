# SPORE BET

Responsive sportsbook foundation for East African and international markets.

## Operating modes
- Virtual demo mode: non-cash credits only; no deposits, withdrawals, or cash redemption.
- Real-money mode: architecture is reserved for a later regulated launch. Real-money wagering, deposits, withdrawals, and payouts remain disabled until legal review, jurisdictional licensing, payment-provider approval, age and identity verification, AML controls, and responsible-gambling controls are implemented and approved.

## Initial scope
- Responsive web app and installable PWA foundation
- Football, basketball, tennis, and rugby navigation
- Demo fixtures and clearly illustrative odds
- Interactive virtual bet slip and demo wallet
- Country-aware architecture for East Africa and international expansion
- Future backend integration points for accounts, odds feeds, settlement, payments, and administration

## Safety and launch requirements
Do not connect live payment credentials or enable real-money wagering in this starter. Before any regulated launch, obtain local legal advice and approvals for each target jurisdiction, implement KYC/AML and age checks, self-exclusion and limits, audit trails, secure payment integrations, fraud controls, and independent security testing.

## Development
This repository currently starts as a static PWA prototype. Production betting requires a secure server-side API, persistent database, authenticated sessions, trusted odds/results feeds, server-side bet validation and settlement, and operational monitoring.
